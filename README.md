# Atoms Demo

输入需求后，智能体拆解任务、生成单页应用，并在工作台中提供可操作预览。继续对话即可在当前源码上迭代。

## 本地运行

需要 Node.js 22 和有可用调用额度的 Atoms API Key。将 `.env.example` 复制为 `.env.local`，只在本机编辑器中填入 `ATOMS_API_KEY`。通过 `ATOMS_MODEL` 指定账户可用的文本模型。Next.js 服务端调用 Atoms Router 首页为该模型提供的 `f.atoms.dev` 模型入口。

```sh
npm ci
npm run dev
```

打开终端显示的地址。输入「做一个温度换算器，输入摄氏温度后用按钮算出华氏温度」。生成后在预览输入 25，检查结果是否为 77。接着发送「再加一个交换温标按钮」，在新版本测试两个换算方向。浏览器刷新后，从最近项目再次打开工作台。

## 构建和预览

- 服务端依次调用模型整理需求和生成应用。失败的源码校验最多触发一次模型修复。构建事件通过流式响应发到对话。
- Next.js 检查模型输出字段和 JavaScript 语法。浏览器在沙箱 iframe 中验证启动并展示预览。预览运行期间报告捕获到的异常，功能行为由用户操作验证。
- 每个通过启动检查的结果保存为一个新版本。查看历史版本只切换预览。恢复旧版会追加新记录，下一次修改从恢复后的版本开始。
- 项目、对话和源码保存在当前浏览器中。生成应用的临时交互数据保存在预览内存中。当前生成范围是单页、无后端的网页应用。
